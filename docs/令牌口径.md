## 四、机制口径（不变量）

- **死区公式**：`calc(<基准>px + <k> × max(0px, 1rem − 17px))`——1rem ≤ 17px 时增量 0，默认档精确=基准 px；宿主缩放 = 调 `html{font-size}`（T15-04）。
- **双写降级**：每令牌两行声明，旧引擎取第 1 行（不缩放但不乱版）。
- **明暗机制**：`prefers-color-scheme: dark` 重定义同一批令牌；组件层零暗档分支。
- **--press 三档判据**（C 类）：中性浅底件 → 换底+缩放；实心品牌/浅品牌底 → 只缩放；整宽行/列表行 → 只换底。
- **mark 色**：只当**文字前景**用（够深可读），禁止当块状 UI 底色。
- **应用根继承字号**：`.app` 16px 死区（0.85 强度）＝**T02-07**，规则在组件层（components.css）。
