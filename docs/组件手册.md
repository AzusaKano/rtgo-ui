## T03 顶栏与返回

### T03-01/02/06 定稿顶栏（.ios-fixed-topbar）
**用途**：子页固定顶栏（detail/exit-review 在用），72px 定高、标题+副标、可带返回钮。
**变体**：固定档（本件）；非固定档用 `.topbar`（T03-01 样片）；≤430px 自动收窄（内距 14、gap 10、标题降档）。
**Do**：标题溢出走省略（类内已带）；右上角动作钮用 42px 圆/胶囊（见 T10-05 同族）。
**Don't**：不要另设高度。72 是定稿基准，改高会牵连吸顶偏移与内容上边距（按例外处理并同步牵连量）。

### T03-02b 顶栏·半透明档（.ios-fixed-topbar.is-translucent）
**用途**：**不做微信小程序**的宿主（Flutter / Web / 原生）用这一档。
T03-02 的「不透明底 `--bg` + 强边框 `--topbar-bd-strong`」是**苹果端小程序渲染 bug 的补丁**
（防穿透 / 防丢线），不是设计意图；没有该 bug 的宿主取 `.98` 半透明底 `--topbar-bg` + `.92` 边框 `--topbar-bd`。
**变体**：**不加类 = T03-02（小程序方案，默认）**；加 `.is-translucent` = 本档。两档只差 `background` 与 `border-bottom`，
几何（72 / 内距 14 / gap 12）与投影共用 T03-02。
**Do**：换宿主时显式声明用哪一档，不靠「看起来差不多」判断。
**Don't**：不要把本档的配色写进 T03-02（会让小程序端失去补丁）；也不要把默认档改成本档（默认必须是小程序方案）。

### T03-02c 顶栏·三子项布局（.topbar-main / .topbar-actions · 宿主新增件）
**用途**：顶栏除了「返回 + 标题组」还要放**右侧动作位**（分享 / 更多 / 主题钮）时用。
**为什么需要**：母本顶栏只有两个子项；`:last-child{flex:1 1 auto}` 成立的前提是标题组恰在最后。
宿主加第三子项后，这条规则会去拉伸**动作钮**，标题反而缩成内容宽。
**变体**：`.topbar-main` = 标题组（吃剩余宽）；`.topbar-actions` = 右侧动作位（不伸缩，`gap:12` 与顶栏同值）。
**Do**：加第三子项时两个类都给；只给 `.topbar-actions`，标题组就没人吃剩余宽度。
**Don't**：不要为了让动作位不被拉伸去改 `:last-child` 那条规则（它是母本 A 类值，改了小程序端就多一处漂移）；
两条新规则必须写在 `:last-child` 之后（同为 (0,2,0)，靠顺序取胜），挪前即失效（M4-深档件 断言看守）。

### T03-03 旧代顶栏（.fixed-topbar / 已移除的 .sticky-topbar）
**用途**：**仅存档参考**。母本已无页面引用（O-01 保留备用）；sticky 档经 M0 拍板移除（效果不佳）。
**Don't**：新页面一律用 T03-02，不要复活旧代。

### T03-04/05 返回钮（.back .back-glyph .home-glyph）
**用途**：左上返回；栈根态用 `⌂`（.home-glyph，加粗+双侧 0.3px 描边补偿）。
**变体**：`‹` 返回 / `⌂` 回首页；按压 = `.press`（换底+缩放）。
**Do**：字形用 Arial 家族 + line-height 27 + translateY(-1px)。真机光学定稿，勿改。
**Don't**：不要用图标字体或 SVG 替换字形（B 件定稿，M0 R-11）。

## T04 表面与卡

### T04-01/02 卡壳（.panel .route-card .summary .segment）
**用途**：内容卡片。`.panel`=表单面板（padding 20）；`.route-card/.segment`=列表卡（padding 18，route-card 底距归零）；`.summary`=汇总卡。
**变体**：默认无边框（靠投影分层）；`.border-for-route` 描边变体。
**Do**：卡内文字起点 = 1px 边框 + 内距（21px 口径），卡外标题对齐用它（见 T04-03）。
**Don't**：不要另配圆角/投影。24px + 标准投影是全工程表面语言。

### T04-03/04/05 卡外标题与分隔（.page-h2 .page-h3 .page-divider .on-bg）
**用途**：内容直接铺页面底时的分组标题与分界。
**Do**：卡外标题 padding-left 21px 与卡内文字对齐；「页面底区块」的胶囊/输入框换 `--input-on-bg`（.on-bg 已带）。
**Don't**：不要在页面底上直接用 `--input-on-card` 底（边界不清，母本为此专门设了 on-bg 变体）。

### T04-06/07/08 屏骨架与空态（.screen .screen-body .empty .app）
**用途**：每屏一个全屏滚动容器；`.screen-body` 管内容宽 780 与底部安全区。
**Do**：空态直接用 `.empty`（居中次级灰）。
**Don't**：⚠ 行内元素不要用 `empty` 做类名（会吃 30px padding，母本出现过该问题；空值态用 `is-empty`，见 T05-06）。

## T05 字段与输入

### T05-01/02/03/04 字段组（.field .label .input .picker .json-input .api-preview）
**用途**：表单字段：标签(13/800 次级灰)+输入。输入框三处底色随表面：卡上 `--input-on-card`、页底 `--input-on-bg`、弹层同口径。
**变体**：`.input`=文本输入；`.picker`=伪输入（点按开选择器，按压 `.press`）；`.json-input`=大文本域；`.api-preview`=调试信息条。
**Do**：min-h 46、radius 14 是触控与视觉基准；占位色走 placeholder 通道（暗档已配）。
**Don't**：不要在深色页面底上用默认占位灰（已配 #6D6D72，勿改）。

### T05-05 字段网格（.field-grid）
**用途**：两列字段（日期+时间这类成对字段）。
**Don't**：网格首字段别留 `.field` 的 margin-top 14（卡内首字段已被归零规则处理；on-bg 网格也归零）。

### T05-06 站点对（.station-pair .station-slot .station-swap .swap-face .is-empty）
**用途**：出发站 ⇄ 到达站合成控件；整槽可点。
**变体**：并排两槽（默认）/ 手动输入模式 `.is-manual`（上下两槽 + `.swap-btn.is-mini`）；空值 `.is-empty`。
**Do**：按压半径 13=容器 14−1px 描边（外圆内直角）；交换钮走正流 flex 列。
**Don't**：⚠ 本控件一律不用绝对定位（母本两轮真机复测）；空值类名必须是 `is-empty`，不是 `empty`（T04-08 陷阱）。

### T05-07 日期时间对（.dt-grid .dt-hit .dt-label .dt-value）
**用途**：无框化日期/时间字段；值=今天/此刻时用品牌色 `.is-now`。
**Do**：两列间 1px `--sep` 竖线只作分隔，不作包围；按压块左右各外扩 10px（.dt-hit 已带），文字不挪位。
**Don't**：不要给它加回边框底色（无框化是定稿口径）。

### T05-08 站点搜索（.station-search-box 族）
**用途**：弹层上的搜索域（底 `--input-on-bg`）。
**变体**：结果行 / 线路点行 / 空态三段。
**Do**：`.station-search-clear` 是裸文字钮（品牌色/700），不挂换底按压。

### T05-09 时刻表查询盒（.schedule-query-box）
**用途**：附加功能内的查询入口盒（`--fill` 底 + 独立主钮）。主钮规格为本件独立口径（min-h 46 / radius 13，见 [件号表](../件号表.md) T05-09 行）；T06-11 为原件号表占位行，已并入本件。
**Do**：禁用同 T06-03（opacity .7）。

### T05-10 开关行（.pick-mode-row）
**用途**：设置行（标题+说明+开关）。开关为原生组件（宿主接，T15-07）。

### T05-11 占位符通道
**用途**：占位色暗档 #6D6D72。Web 用 `::placeholder`，类本体（.input-ph/.dtp-ph）保留。

## T06 按钮族

### T06-01/02 主/次按钮（.actions .primary .secondary + button 重置）
**用途**：一屏主操作（实心品牌）+ 并列次操作（品牌浅底）。
**变体**：`.actions` 内自动 48px 高/不挤压；`.advanced .actions` 换行加宽次钮。
**Do**：主钮一屏一颗；容器 `.actions` 负责布局，别绕开它裸排。
**Don't**：⚠ 次钮不用灰底，"次级"由品牌浅底表达；button 重置与 `!important` 三件用于压原生默认，删掉会宽出容器。

### T06-03 分享/保存钮（.share-btn）
**用途**：页底整宽次级动作（品牌浅底）。禁用=opacity .7（只降透明，勿换灰底）。

### T06-04/05 交换与选择（.swap-btn .swap-btn.is-mini .station-select-btn）
**用途**：交换（44 整宽 / 26 迷你胶囊）、输入行尾"选择"钮。
**Do**：迷你形态用 `.is-mini` 独立类（母本复测：靠祖先选择器给形态会漏）。

### T06-06/07 对话框按钮（.dtp-btn .snp-btn）
**用途**：弹层内取消/确定。
**口径**：取消 = `--fill-plain` 底 + 品牌字（Flyme：主次靠底的浓淡，不靠颜色降级）；确定 = `--brand-tint` 底 + 品牌字（定稿：最终动作不用实心块）。
**Don't**：不要把取消钮换成 `--fill`（那是为 --sheet 面板调的，压在卡底上偏重）。

### T06-12 独立按钮原语（.btn-primary .btn-secondary）
**用途**：脱离 .actions 容器的独立按钮（弹层内、独立行、工具页）。值 1:1 镜像容器档（48/radius14/品牌白字/15px·750；次钮 min-w 76）。
**Do**：禁用同主族（opacity .7）；挂 press-scale。
**Don't**：不要与 .actions 档混用于同一行（容器档管布局，原语档管单颗）。

### T06-08 出口/完成钮（.nb-gate-btn .nb-done .is-dim .is-primary）
**用途**：弹屏唯一写回出口。品牌实心 = `.is-primary`/`.nb-done`；不可用 = `.is-dim`（opacity .5）。
**Don't**：不可用态不要换灰底（与品牌色打架，深浅两套还要各调）。

### T06-09 导出钮（.ex-btn）/ T06-10 展开钮（.expand-btn .route-actions）
**用途**：维护页工具钮；列表卡底部"路线预览"文字钮（min-h 40 触控，catchtap 阻冒泡语义由宿主接）。
**Do**：展开钮按压带 `.expand-hover`（临时底 + 16px 圆角）。

## T07 胶囊族

### T07-01 筛选胶囊（.chip .chip.active .toolbar）
**用途**：板块切换/排序筛选的标准胶囊。全工程唯一口径：44 高（lh 42 = 内容盒高，真机校准）、`--pills-bg`、13px/500；选中转品牌实心。
**Do**：横向溢出配 `.chip-bar-wrap + .hscroll-fade.is-page`（页底渐隐）。
**Don't**：⚠ 不要写「紧凑版 36px」这类页面特例（timetable 曾有过，已删除并统一）；行高 42 不要改成 44（半行距取整会偏半像素）。
**（真机复测 2026-10-31）**：`.chip` 的 `display:inline-block !important` 在 Web 端连内联 style 都会压过：复测页 B 口径样片给 .chip 内联 `display:inline-flex`，flex 居中整体失效、文字顶格（Δ-12.7css）。给挂 .chip 的元素做布局实验前，先核对以上三处。
**注（2026-10-31）**：存在两种渲染等价的居中口径：42 内容盒行高（母本 / RTGo）与 .132em 上内距补偿（另一产品 ui-kit）。两者都是近似解，真机上均不能保证逐像素归零。反证：另一产品用户真机上 .132em 未达其注释声称的 Δ=0；字体度量随设备 / ROM / 字号变化，单系数 em 补偿在不同字号档数学上不自洽。跨设备复测（墨迹 bbox 按设备族出值，工具用 WorkBuddy scanmulti.mjs 那套）通过前，两边保持现状，不要互相搬运补偿值。

### T07-02 线路选择胶囊（.station-line-chip .station-line-dot .line-expand-btn）
**用途**：站选器内按线路过滤：34 高、`--card-lift` 底、**1px `--border` 描边**；active 白字白点。
**Do**：横滑条右缘渐隐端用 `--sheet`（面板底）；展开钮 34px 圆（`--pills-bg`）。

### T07-03/04/05 线路色胶囊（.line-pill .mode-badge .seg-type）
**用途**：线路标识。`line-pill`=列表/详情（min-h 30，白字 800）；`mode-badge`=方案卡轴（min-h 26，白字 700）；`seg-type`=段类型。
**Do**：线路色是**业务数据色**，一律 wxml/行内注入，不进资产；浅色线路（黄系）白字对比不足是已知共有问题。
**Don't**：snp 弹屏内 26px 档走 `.snp-panel .line-pill` 作用域（勿全局改 30→26）。

### T07-06 站序胶囊（.station-chip）/ T07-07 最近查询（.recent-combo）
**用途**：途经站/组合缓存。组合胶囊 999 圆、`--fill` 底、13px/400（与功能按钮的 8~14px 圆角刻意区分）。
**Do**：横向滚动配 `.recent-scroll-wrap + .hscroll-fade`（卡内渐隐端 `--card`）；可点组合挂 `.press`。

### T07-08 附近站条（.nearby-bar 族）
**用途**：站选器内定位建议条。骨架态 `.nearby-skeleton`（1.2s 脉冲）。
**Do**：条底 `--fill` 与搜索框 `--input-on-bg` 区分层级；站胶囊落深表面用 `--input-on-bg`（同款胶囊落深表面提亮一档的口径）。

### T07-09/10/13 场景胶囊（.dtp-chip .snp-chip .er-nav-btn .ex-chip）
**用途**：dtp 快捷加分钟（34/`--input-on-card`）；snp 口名（44/`--fill`/radius 12）；维护页翻站（chip 复用+press-flat）、采集页已采站切换。

### T07-11 第 x 程徽标（.trip-badge .is-circle）
**用途**：详情页"第 N 程"。`.is-circle`=品牌实心圆+镂空数字（数字取 `--card`=下层透出，深色自动成立）。
**Do**：数字字号用 `--fs-tag-10`（低放大强度，不撑破 20px 圆）。

### T07-12 警示徽标（.route-badges .warning-badge）
**用途**：结果卡右上纵栈警示（默认 `--warn` 实底白字）。窄屏降 112 宽/34 高/11px。

### T07-14 sd 导航钮（.sd-nav .sd-ex-letter）
**用途**：车站信息弹层"导航"入口（brand-tint+品牌字+clip-path 箭头）；口字母块。

### T08-04 站名/元信息（.station .meta .meta-line .formation-tag .lastStationDetail）

### T08-05/06 换乘框（.transfer-box .intercity .inner-transfer .transfer-note）

### T08-07 途经站行（.leg-*）

### T08-08/10 方案卡轴（.axis 族 .mode-gate）

## T13 按压档（C 类·刚性·禁 ripple）

### T13-01/02/03 三档与基态组
| 档 | 动作 | 适用 |
|---|---|---|
| `.press` | 换底 + scale .96 | 中性浅底件（--fill/--card/--input-*） |
| `.press-scale` | 只 scale .96 | 实心品牌/品牌浅底（刷灰会色相跳变） |
| `.press-flat` | 只换底 | 整宽行/列表行（缩放会与网格错位） |

**参数**：250ms，两个方向共用 cubic-bezier(.33,.33,.67,1)（起手 1.0× 不窜、缓停收尾）。
**铁律**：基态 transition 组必须排在按压档之前（同特异性后者胜）；新元件必须补进基态组，否则松手瞬间弹回。map/sd 组多 bg+opacity 过渡是 C 手感差异，禁止合并（M0 R-07）。

### T13-04 接线（宿主）
挂摘类语义 = pointerdown/up 立即（start/stay=1ms 等价）；打断时 transition 从当前值折返（reversing）。Web 也可 `:active`。

### T13-06 状态变色（非按压，别混进按压档）
`.tt-main` 展开行 0.16s 变底、`.nb-row.is-picked` 即时底：这是状态迁移，不是每次按下的一次性反馈，故不在 C 类三档；新增选中 / 展开变色按本件口径（transition 挂在基类）。
### T13-05/07 透明度特例与禁用
裸文字钮不挂三档：`station-nav-hover`(opacity .55)、`custom-entry-line:active`(.6)、`recent-clear:active`/`er-add:active`（变色）。禁用一律只降透明（.7/.5/.4），不换灰底。

### T13-08/09 组件前缀档
dtp（round/scale/flat）与 snp 前缀档参数与主族逐字相同；已选格子按压保 brand。

### T13-X 多文件/多主题宿主的按压级联陷阱（v1.3 回流自另一产品实机）
单文件资产（RTGo 现状）不暴露这三个坑；**一旦样式拆多文件或引入主题层，按此办理**：
1. **自有底色控件挂 press-flat 会被后加载的底色吃掉**：`.press-flat{background:var(--press)}` 与控件底色同为 0,1,0，加载顺序靠后的胜。实例：另一产品加载序 tokens→theme→ui-kit→app，app 的底色永远胜，2026-10-22 实机复现「取消没有按压反馈」。解法为两档类名补丁：`.控件类.press-flat{background:var(--press)}`（0,2,0）。新增此类控件必须补进补丁组。
2. **press-scale 是自带底色控件的安全档**：只写 transform，不参与 background 竞争。
3. **选中/展开态按压保底色**：`.prefs-opt.active.press-flat{background:var(--brand)}`。实心承白字换 --press 会让白字落浅底不可读（与母本 `.dtp-press-flat.is-selected` 同口径）。
4. **反查方法**：按住不放读 computed background，与松手时相同即为被吃。
