RTGo_slate — 移动端设计系统

全部数值取自一个真实上线的移动端产品，1:1 照抄，不是凭感觉调出来的。改观感只改令牌，不要改组件值。 每个样片左上角是件号 与类名；按压档样片可按住体验（JS 复刻 hover-class 挂摘类语义，含从当前值折返）。 用法/变体/Do-Don't 见 组件手册。

ID 索引（自动生成自样片标注；点击跳样片）

T01 色彩令牌（浅/暗两套，prefers-color-scheme 自动切换）

值展示由 JS 从本页实际计算样式读取（getComputedStyle），gallery 里不写死任何色值——令牌是唯一真值。右上角可切主题。

T02 字号令牌（rem+max 死区，双写降级）

默认档 1rem=16px≤17 → 增量 0，字号精确=基准 px；宿主调 html{font-size} 即得母本「系统字号档位」缩放（T15-04）。

T03 顶栏与返回

顶栏两档：.ios-fixed-topbar（72px）为**默认档 = 微信小程序方案**——不透明底 --bg + 强边框 --topbar-bd-strong，那套是修苹果端小程序渲染 bug 的补丁；不做小程序的宿主（Flutter / Web / 原生）加 .is-translucent 用半透明档（T03-02b）。.fixed-topbar 为历史代际（O-01 保留备用，其底色/边框即半透明档的出处）。.sticky-topbar 经 M0 拍板已移除（O-02）。

T04 表面 · 卡片 · 页面骨架

卡壳 radius 24 / 投影 0 10px 28px rgba(35,47,78,.08)；卡外标题缩进 21px（1px 边框 + 20px 内距的口径）。

T05 字段与输入

输入框 radius 14 / min-h 46 / 底随表面（卡上 --input-on-card、页底 --input-on-bg、弹层同口径）；站点对 h52、外圆 13 内直角。

T06 按钮族

主钮 48px 实心品牌底；次钮 --brand-tint 底；对话框取消钮走 Flyme 口径 --fill-plain 底 + 品牌字（主次只靠底的浓淡）。禁用一律只降透明度（0.7 / .is-dim 0.5），不换灰底。

T07 胶囊族

标准筛选胶囊 44px 高（line-height:42 = 内容盒高，真机校准值）；线路选择胶囊 34px；线路色胶囊白字 800。线路色为业务数据色，由 wxml 内联注入（演示同口径用 inline style）。

T08 时间轴（方案详情主轴）

行网格 57/25/1fr；节点 17px（换乘 20px，translateY(-1.5px) 同心补偿）；轨线 4px；时刻 17/850 顶对齐 + translateY(4px) 中线对齐（推算时刻 4.4px，不能沿用 4px——母本真机定稿）。

T09 城际时刻表

行网格 72 / 1fr / 20 / 1fr / 54 / 24（340px 档收窄）；表头吸顶 .tt-head-wrap；展开行 .is-open 转 --brand-tint；chevron 是几何绘制（translate ±2.5px 校准值），不是字形。

T10 弹层壳（形态 × 配色 两个独立维度）

半屏四件：通栏 / 只上圆角 24 / 贴底（safe 由 padding 吃）/ 只向上投影。配色独立选档：--sheet（同页底）或 --card（亮一档，dtp）。悬浮对话框档：宽 calc(100%−32px)、四角 24、投影向下。点「打开」体验 380ms 回弹滑入（62% 处 −3px 折返）。

T11 徽章与警示

警示卡三态：--warn（默认/紧张）→ .status-late 红 → .status-ok 绿，投影随主色。文字时刻同三态（.lasttime-time-warn 族）。

T12 图标

两族：①CSS 几何 chevron（.action-glyph 方块取上/右边框旋转，±1.5px 真机光学补偿；translate 必须写在 rotate 前）②mask SVG 单枚图形（零色值，颜色=currentColor，深浅自适应）。图形字符（‹ ⌂ × ⇄ ▾）按母本原样保留，禁 emoji 化。

T13 按压档（C 类 · 刚性 1:1 · 禁 ripple）

曲线 cubic-bezier(.33,.33,.67,1)（起手 1.0× 不窜、峰值 1.33×、缓停收尾）、时长 250ms、缩放 .96。三档判据：.press=中性浅底件（换底+缩放）；.press-scale=实心品牌/浅品牌底（只缩放，刷灰会色相跳变）；.press-flat=整宽行/列表行（只换底，缩放会与网格错位）。基态组必须排在按压档之前（同特异性后者胜——母本七轮教训）。

T14 进出场动效

切屏 screen-in 220ms ease-out（translateY 12px + backface 防闪白）；局部一律 rail-fade-in（160/180/220ms，opacity-only——不在含 sticky/固定子结构的容器上造包含块）；半屏滑入 380ms cubic-bezier(.32,.72,0,1)，115% 起点、62% 处 −3px 折返回弹。

T17 跨项目回收件（origin=另一产品，真值源=其 ui-kit/app.css）

这些件不在本系统的原始母本里 —— 由另一个产品开发时沉淀、经对账回收入册（T17 段，真值源是该产品的样式文件）。改名两项：.tt-flat-*（平铺式时刻表）、.facts-plain/.fact-plain（防 T08-11 撞名）。.tag 的 .132em 补偿挂 Y-R1 开放项。

T17-16 版式参考：文件详情页整页 pattern

pattern = 组件的 approved 组合示范：由 T17-14 详情头 + T08-11 facts（plain 变体）+ T06-12 原语钮 + T04-01 panel + T17-05 公告 + T17-15 目录族拼装。**整页编排不进资产包**——本节 HTML 即编排参考（间距节奏：区块间 14px、页边 14px、panel 内 14 16）。

T19 票务指南弹层（origin=母本新增页 intercity-guide）

壳形态新档：**面板高度内容自适应、上限 86vh**（内容短的弹层用，固定 78vh 会下半截空）；滚动区**通栏化**（margin -14px 抵消面板内边距 + padding 补位，滚动裁剪边界退到面板边缘——卡片阴影不再被裁出硬边，.sd-body 同款）。
